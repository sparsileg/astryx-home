Full Feature List

A media collection tracker

Core Library Management

  • Full reading history — track books you've read, with re-reads recorded as separate entries rather than overwriting the last one.
  • Prioritized to-be-read list — maintain a ranked reading queue with manual reordering.
  • Personal library catalogue — keep a record of the physical and digital books you own.
  • One consistent Add/Edit flow — the same experience across My Library, Books Read, and To Be Read.
  • Check-out / check-in tracking — loan books to friends with patron name and date recorded.
  • One record, shared everywhere — a normalized data model means the same physical book is one record, not a separate copy per list.
  • Mark Finished, instantly — move a book from To Be Read or My Library into your reading history without re-typing title or author.
  • Built to grow beyond books — the schema is designed to extend to DVDs, CDs, and other media types without a rework.

Organization & Tagging

  • Unlimited, flexible tagging — no rigid category system to fight against.
  • Full Tags management — add, rename, and delete tags, each with a live usage count.
  • Sort tags your way — by name, usage count, or last updated.
  • Safe tag deletion — optionally substitute another tag so removing one doesn't leave books untagged.
  • Tag autocomplete — suggestions drawn from your existing tag vocabulary as you type.
  • Built for large tag vocabularies — a scrollable tag picker that stays usable with hundreds of tags, not just a handful.

Search & Filtering

  • Instant quick search — search across title, author, and tags at once.
  • Combined text and tag search — mix a free-text word and a #tag in a single query.
  • Tokenized search — multiple words are matched together automatically; quoted phrases match exactly.
  • Advanced filter panel — per-field operators including contains, equals, is empty, greater/less than, and date ranges.
  • Live filtering — results update as you type or adjust filters, no "Apply" button required.
  • One-click reset — clear quick search or advanced filters instantly.
  • Adjustable records per page — from compact pages to viewing your entire library at once.
  • Fast pagination — jump straight to any page of a large library instead of clicking through one page at a time.
  • Live page preview — see what you'll land on before you get there while navigating pages.

Cross-Collection Intelligence

  • One book, one record — reading history, to-be-read status, and library ownership all reference the same underlying item.
  • Find Duplicates & Merge — consolidate accidental duplicate entries with field-by-field conflict resolution.

Dashboard & Statistics

  • At-a-glance dashboard — total books, total pages, this-year progress, and average pace.
  • Recently finished — your latest completed books, right on the dashboard.
  • Reading goal tracking — visual progress against a daily page target.
  • What's Next — a preview of your top-ranked to-be-read titles.
  • Books checked out — a quick card for keeping track of loaned books.
  • Rearrangeable dashboard — reorder cards to match how you actually use the app.
  • Yearly statistics — year-over-year trend charts for your reading.
  • Top tags by usage — your most-used tags, visible without digging through the Tags view.

Data Ownership & Portability

  • Open, human-readable export — your full library, exported in a format you can actually read.
  • One-click backup — with optional compression.
  • Guided restore — a two-step flow with a clear before/after comparison before anything is overwritten.
  • Nothing locked in — your library data is yours, in a format you can reuse without Collectyx.

Cross-Platform

  • Native desktop app — for Windows, macOS, and Linux — fast, offline-first, local use.
  • Browser-based web version — no install required.
  • Consistent everywhere — the same features and behavior on desktop and web.
  • Responsive layout — adapts from a full desktop sidebar down to a compact mobile view.

Customization & Accessibility

  • Selectable visual themes — including a low-light/dark option.
  • Adjustable font size — independent of your browser or OS settings.
  • Colorblind-considerate design — status and meaning are never conveyed by color alone.
  • Context-aware navigation — a collapsible menu that shows only the actions relevant to what you're currently doing.

Privacy & Data Control

  • Local-first architecture — your library lives on your device by default, not in someone else's cloud.

On the Roadmap

Planned, not yet available.

  • Multi-device sync — optionally follow your library across desktop and web installs.
  • ISBN barcode scanning — fast mobile entry by scanning a book's barcode.
  • Android companion app — bringing Collectyx to your pocket.
  • Beyond books — support for additional media types, using the same underlying library the book features are already built on.
