Web vs. desktop

WebDesktop
Storage Browser (IndexedDB) SQL database file
Access Any device, no install Installed app
Data security Browser cache clears = data loss File deletion/drive failure = data loss

Backup regularly to an external drive or cloud storage

Try it, stay, or switch — your call. Start with the web version to try Collectyx out. Stick with it as long as you like, or migrate your backup to the desktop app anytime for a local SQL database so that your data is not stored in the web browser. Same backup and restore format either way, so nothing is lost switching.
