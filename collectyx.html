Feature list

  • Track your library — mark books as owned, reading, finished, or on the wishlist.
  • Log reading progress — track page or percent complete so you can pick up where you left off.
  • See yearly stats — totals by month and genre turn a shelf of books into a shape you can see.
  • Export & backup — back up your library at any time, in a format shared between the web and desktop versions.

Web vs. desktop

WebDesktop
StorageBrowser (IndexedDB)SQL database file
AccessAny device, no installInstalled app
Backup riskBrowser cache clears = data lossFile deletion/drive failure = data loss
Backup methodExport/backup regularlyBack up the .db file regularly

Neither version backs itself up automatically — back up regularly, whichever you use.

Try it, stay, or switch — your call. Start with the web version to try Collectyx out. Stick with it as long as you like, or migrate your backup to the desktop app anytime for a local SQL database. Same backup format either way, so nothing is lost switching.
